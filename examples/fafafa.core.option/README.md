- Linux/macOS：`examples/fafafa.core.option/BuildOrRun.sh`
- Windows：`examples\fafafa.core.option\BuildOrRun.bat`

## What to run first

- `example_option.lpr`

## Generated outputs

- `bin/` 和 `lib/` 只代表本地构建结果，不是 source-of-truth。
- current-entry 应回到 README、`BuildOrRun*` 脚本、`.lpr` / `.lpi` 源文件，而不是把生成产物当成稳定入口。
